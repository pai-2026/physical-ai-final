# Step 2: 動作生成と学習用の教師データ作成

Step1で作成した環境を使い、ブロックを掴む・持ち上げる・運ぶ・置く動作を作成。
これらの動作を使って、学習用の教師データを作成する。

## 構成概要

- **IK**: TCPを垂直姿勢に保ちながら目標位置へ動かすため、逆運動学を実装。
- **把持**: 把持時の相対位置を保持し、対象物を手先に追従させる簡易方式。
- **搬送**: 持ち上げ・水平移動・降下・退避の経由点を生成。
- **成功判定**: ブロックの位置・高さ・姿勢から配置や積み上げを判定。

## 工夫した点

- **手先の傾き**: 位置合わせだけでは姿勢が崩れるため、下向きの目標姿勢を設定し、IKの回転誤差とヤコビアンの回転成分に3.5倍の重みを付けた。
- **把持時の反発・不安定さ**: 接触だけに頼らず、把持時のTCPとの高さの差を保持して追従させる簡易把持を採用。保持中はブロックを直立姿勢に揃えた。
- **搬送時の接触**: 斜め移動でトレイ縁などに当たるのを避けるため、垂直リフト・水平移動・垂直降下・解放後の退避に動作を分けた。
- **不要な視覚的手がかり**: 学習時に補助マーカーを頼りにしないよう、TCPと目標位置のデバッグ用サイトを透明にした。
- **教師データの多様化と判定**: 初期配置・置き場所・積む順序・指示文を変えて動作を生成。位置・高さ・直立姿勢・土台の保持を確認する成功判定を用意した。
