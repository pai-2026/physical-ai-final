# Step 4: ポリシー学習

収集した教示データを使い、SmolVLAを学習。

## 構成概要

- **SmolVLA**: ブロック300エピソードで学習済み。既定は10,000ステップ。
- **ACT**: 日用品の比較用スクリプトを準備。本番学習は未実施。
- **Colab**: 日用品の比較学習用ノートブックを同梱。全セルの実行確認は未実施。
- **今後**: Pi0.5・GR00Tを含めたモデル比較を予定。

学習本体はLeRobotを利用し、データ・モデル・保存先を指定する起動スクリプトを作成した。
既存の保存先がある場合は、別の`--output_dir`を指定する。

```bash
.venv/bin/python Step4-Training/train_smolvla.py
```
